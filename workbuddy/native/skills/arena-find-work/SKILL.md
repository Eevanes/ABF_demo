1. 核对 [能力绑定](../../CAPABILITIES.md)。只有原生查表在当前企微渠道和角色范围通过验收后，才使用其实际工具读取「作品」「版本」；否则调用已验证的兼容查询，说明入口；两者都不可用时报告失败。
2. 使用队名／作品名过滤并处理全部分页。无匹配说明未找到；多候选列出作品编号、队名、作品名，等待确认。结果只来自本次读取。
3. 按底层授权读取详情和版本；共享管理员连接不能支持个人内部查询。核对最新版本指针和版本行，不一致时生成异常草稿。
4. 返回作品编号、队名、作品名、最新版本及来源；查版本时附实际 tag、commit SHA 和 GitHub 链接。连接器异常和权限过期时明确说明实时查询失败。

完成标准：来源与原表一致，候选处理明确，权限不扩大，系统字段保持只读。真实用例：S01、S02、S05、S06、S08。
