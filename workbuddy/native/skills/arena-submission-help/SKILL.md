1. 核对 [能力绑定](../../CAPABILITIES.md)，通过已验证的 WorkBuddy 资料库检索适用角色的已批准文档；尚未启用时用兼容规则工具，缺正式来源则报告待确认。
2. 回答附文档标题、来源、规则版本和生效日期。规则更新时引用本次可检索版本；多个版本冲突则停止给出执行结论并交 Owner 确认。
3. 提交指导指向选手自己的 Arena MCP 三工具，作品身份由服务端验证。告知同一次重试保持 `submission_id` 和内容；遇到“Git 已保存、登记失败”先查版本并交后台对账。
4. 资料库的截止时间解释不改变服务端配置；二者冲突必须升级，不能替用户承诺延期。未知赛制及处罚交人工裁决。

完成标准：有依据、有版本、无凭据、无虚构提交成功。真实用例：K01、K02、K03、K05、K06、K09、K10。
