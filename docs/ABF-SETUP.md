# ABF 现场配置

已创建：ABF · Arena 比赛运行层 Demo，真实链接仅保存在本机 `SMARTSHEET_URL` 环境变量，不随源码上传。

机器人名称为 `test机器人`。在企业微信单聊发送“山海队的作品ID”已真实验证成功，并回写到反馈表。

接入命令（Windows）：

```powershell
# 只在需要重新扫码绑定时执行；机器人凭据只写本机用户环境变量。
.\Run-Demo.ps1 -Mode connect-wecom

# 已有测试文档配置时只做结构核对，不重复创建文档。
.\Run-Demo.ps1 -Mode provision-wecom

# 用户在本机页面输入 DeepSeek Key，不发送到聊天。
.\Run-Demo.ps1 -Mode connect-model

# 单实例启动 MCP + 企微长连接 + 云端登记镜像。
.\Run-Demo.ps1 -Mode live
```

服务启动时显式载入本机用户环境变量，避免父进程尚未刷新环境导致“配置过但子进程找不到”。
密钥页验证成功后，运行中的机器人会在后续消息时加载模型 Key；没有 Key 时明确使用离线演练模式。

目前 CLI token 到期后的自动换取尚未接入。出现 853004 时先停止云端写入，再按官方签名协议刷新本机环境 token，不回退成未经验证的写入。

本阶段仅新增专用测试表格和演练数据，没有修改其他企业文档、成员权限或生产数据。CLI 授权用户与 SDK 回调身份分别验收，不能自动将第一个发消息的人提升为管理员。
