# 工作人员演练

1. 运行 `Run-Demo.ps1` 创建虚构报名、提交、值班和反馈数据。
2. 用 `arena ask` 查询作品或规则。普通选手仅看到作品编号、名称、队名；工作人员白名单通过 `STAFF_USERIDS` 配置。
3. 示例知识文件位于 `src/arena/knowledge`；岗位 SOP 位于其 `sop` 子目录。示例内容不代表正式比赛规定。
4. `arena feedback-report` 返回点踩和待人工处理记录。CLI `arena rate` 仅能评价对应用户自己的反馈。
5. 本地转人工不发消息。真实机器人创建、配置并通过收发验收前，不应把记录出现当作通知送达。

ABF 已创建比赛专用测试表格，当前以 SQLite/Git 维护提交状态并镜像到企微。工作人员可补充「作品」表中的别名，后台约 60 秒回流。
动态值班完整回流、原生点踩事件和真实转人工通知仍待后续验收；本次单聊只验证 participant 权限。不要向真实报名名单或生产表批量导入演练数据。
